# L&S Enterprises – Road Safety & Fleet Training

L&S Enterprises is a premier road safety, vehicle inspection, and fleet logistics training company based in Chennai, India. Backed by 35 years of ex-army professional expertise, this website serves as a high-conversion, ultra-modern digital storefront to attract corporate transport clients.

## ?? Features

- **Cinematic Parallax UI:** Smooth, high-performance scroll animations powered by GSAP and ScrollTrigger.
- **Modern Tech Stack:** Built as a lightning-fast static Single Page Application (SPA) using HTML5, Tailwind CSS, and Vanilla JavaScript.
- **Serverless Contact Form:** Fully integrated with Web3Forms for instant email delivery without requiring a backend server.
- **Responsive Design:** Pixel-perfect scaling across mobile, tablet, and ultra-wide desktop screens.
- **Full SEO Optimization:** Complete with JSON-LD schema markup, Open Graph tags, Twitter cards, and keyword-rich alt text to dominate local search results.

## ??? Technologies Used

- **HTML5:** Semantic and accessible document structure.
- **Tailwind CSS:** Utility-first styling injected via CDN for rapid, scalable UI development.
- **GSAP (GreenSock):** Industry-standard library for complex, buttery-smooth scroll animations.
- **Web3Forms:** Serverless form submission handling.

2. Leave all build settings as their defaults (No framework).
3. Click **Deploy**.
